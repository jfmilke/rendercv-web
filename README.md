# RenderCV Web

## Project

This project is about creating a simple Web GUI for the CLI application [render-cv](https://github.com/rendercv/rendercv).

## GUI Specifications

- Text editor with YAML highlighting and YAML syntax correctness check on the left.
- PDF render preview on the right.
- Button or drag-and-drop to upload a local YAML file into the textfield.
- Button to download the web YAML.
- Button to download the generated PDF.
- Button to generate a PDF.
- Text showing which render-cv version is being used.
- Output window at the bottom showing all the output generated by the rendercv CLI
- The web UI should use a dark blue background, rounded corners.
- Text fields have a dark grey background, white mono text (the YAML editor should highlight code).
- It should all look quite modern and minimal.

## Security Specifications

- Uploading the YAML file happens on the client (Browser) in a text only field.
- Once the Generate PDF button is hit, the text content will be sent to the server.
- Explore required safeguards for the intended architecture to make this application as safe as possible against attacks.
- The server should be safe at all times, do as much as can be mindful done in the Client browser.
- render-cv is meant to be run as a docker container at will using `ghcr.io/rendercv/rendercv` image

## General Specifications

- Research and propose a safe and reliable stack to use for this application.
- The whole application should run as a docker compose stack if possible, to easily host it locally and/or on a server.
- It should allow a reverse proxy pointing to it.
- HTTPS/SSL without reverse proxy can be thought about too, but is not too important.

## Running locally

```bash
cp .env.example .env
docker compose up --build
```

Then open http://localhost:8000.

To enable the optional profile-photo upload feature (off by default — see the design spec for the security trade-offs this accepts), set `IMAGE_UPLOAD_ENABLED=true` in `.env` before starting.
